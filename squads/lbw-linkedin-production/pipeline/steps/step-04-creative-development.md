# Step 04: Desenvolvimento Criativo

## Context Loading
- Leia a direção aprovada, a pesquisa, `tone-of-voice.md` e `linkedin-post.md`.

## Instructions
1. Crie três ângulos diferentes para a pauta.
2. Para cada ângulo, escreva um hook e explique o público, a tensão e o CTA.
3. Escolha uma recomendação para o post de LinkedIn.
4. Não escreva ainda a versão final; entregue direção para a redatora.

## Output Format
```markdown
# Brief criativo
## LinkedIn
Ângulo 1:
Ângulo 2:
Ângulo 3:
Recomendação:
```

## Veto Conditions
1. Os três ângulos são apenas variações da mesma frase.
2. O hook não deixa claro o problema ou benefício.

## Quality Criteria
- [ ] Há contraste ou tensão real.
- [ ] O ângulo é original para a LBW.
- [ ] O CTA é coerente com o estágio do público.
