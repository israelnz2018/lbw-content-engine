# Domain Framework

1. Define the audience segment and awareness level.
2. Choose one content pillar: carreira, análise de dados, melhoria contínua, método GATE, plataforma LBW ou consultoria parceira.
3. Start with a concrete workplace tension.
4. Teach one usable idea with an example.
5. Connect the idea to a next action without exaggerating the promise.
6. Adapt the same insight natively to Reels or LinkedIn.
7. Review factual accuracy, clarity, originality, accessibility, and CTA.
