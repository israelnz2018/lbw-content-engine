# Automação de carrosséis

Execute na raiz do projeto:

`node squads/lbw-carousel-production/automation/render-carousel.mjs caminho/config.json`

O JSON deve seguir `carousel-input.example.json`. A saída contém PNGs 1080 x 1350, um PDF para LinkedIn e o texto do carrossel. Todos os nomes começam pela data de criação.
